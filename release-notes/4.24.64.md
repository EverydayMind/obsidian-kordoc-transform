## What's new

- **Re-enabling or updating Verbex keeps KorDoc Transform working.** The plugin now registers a fresh provider each time, so its registration no longer stays unfinished and blocks other plugins from saving.
- **Tools are found in either language.** Tool keywords carry Korean and English words whatever the app language is.
- **Converting a file already in the vault no longer copies the source.**
- **Clearer commands and notices.** Document tool commands are prefixed "Document tools:". The Markdown to HWPX export notice has an Open button, the preview badge says "Approximate preview", and MCP connection details mask the token.
- **Frontmatter.** `converted` is local time with offset, and `tool` names the plugin version and the engine version.
- **Settings are grouped under four headings.**

The bundled engine stays at kordoc 4.24.59. After updating, approve the plugin again in Verbex settings › Tool management › Tool approval.
