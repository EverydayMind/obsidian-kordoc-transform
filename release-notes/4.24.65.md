## What's new

- **Documents marked AI-private in HWP Hands stay private.** KorDoc Transform's agent tools, the Verbex session provider, the host index text and local MCP reads now refuse those documents (and their `.index.md` notes) before opening the file.
- **Export notice opens the result where you edit it.** The Open button opens the exported file in the HWP Hands editor when that plugin is enabled, and in the KorDoc preview otherwise.
- **The export notice reports what did not come through as intended.** It counts blocks that Obsidian draws as charts or views (plotly, mermaid, dataview and so on) but that were written into the document as code text, and images that could not be embedded.
- **"1 document to convert"** is now worded correctly for a single document.

The bundled engine stays at kordoc 4.24.59, and the OCR pack is unchanged (4.24.59). The Verbex tool list is unchanged, so no re-approval is needed.
