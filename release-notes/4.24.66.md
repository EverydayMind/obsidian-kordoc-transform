## What's new

- **Works with the newer Verbex document-reading handshake.** When Verbex advertises the shared host-capabilities contract, KorDoc Transform now hands it document text through the standard provider channel (with approval) and reports which Hangul or PDF windows are open, so Verbex does not edit a document you are working on. Older hosts keep using the previous direct call.
- **No duplicate registration with the newer host.** When Verbex takes over through the new channel, the older tool registration is withdrawn, and it is checked again once the workspace has finished loading, so plugin load order no longer matters.
- **Cleaner extraction results.** Document text results no longer carry empty fields, which the host rejected.

The bundled engine stays at kordoc 4.24.59, and the OCR pack is unchanged (4.24.59). The Verbex tool list is unchanged, but as after every update, Verbex asks you to approve KorDoc Transform again before the agent can use it. Verbex 0.2.0 and later require this version to save Hangul and PDF documents.
